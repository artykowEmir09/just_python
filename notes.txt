1. mkdir my-personal-os
Purpose: Creates a new directory (folder).
- mkdir = Make Directory.
- my-personal-os = The name of the folder you want to create.
Example:
mkdir my-personal-os


PowerShell creates this folder in your current working directory.

For example, if you are currently in:
C:\Users\USER\Desktop


The new folder will be:
C:\Users\USER\Desktop\my-personal-os


2. cd my-personal-os
Purpose: Moves you into the folder you just created.
- cd = Change Directory.
- my-personal-os = The destination folder.
Example:
cd my-personal-os


Your PowerShell location changes from:
PS C:\Users\USER\Desktop>


To:
PS C:\Users\USER\Desktop\my-personal-os>


3. What happens when you combine them?
mkdir my-personal-os
cd my-personal-os


Your folder structure
Desktop

my-personal-os
Current directory



4. Try these additional commands

pwd	Shows your current directory

cd ..	Moves one directory backwards

clear	Clears the terminal
cd ~	Moves to your home directory

1. python -m venv .venv
Purpose: Creates a virtual environment for your Python project.

Let's break it down:
Part	Meaning
python	Runs the Python interpreter
-m	Runs a Python module as a script
venv	Python's built-in virtual environment module
.venv	Name of the environment folder

What happens?

Python creates a folder called .venv inside your project.

Your structure becomes:
my-personal-os/

.venv/
New

 Scripts/

 Lib/

 pyvenv.cfg


 Why do we need a virtual environment?
Imagine you have two Python projects:
- Project A needs Django version 4.
- Project B needs Django version 5.
Without separate environments, package versions can conflict.

With virtual environments, each project can have its own dependencies.

Think of a virtual environment as a separate workspace for Python packages.
